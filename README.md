# 行星模拟器 · 分享预览

2026-10-30 的 Phase 11 体验版，尚未冻结或最终验收。

这是编译后的静态网页发布仓库。开发源代码、用户存档、诊断记录、证书及录屏不在本仓库。

点击天体进入近景；点击画面空白返回；拖动旋转、双指或滚轮缩放。下方可控制播放、速度与时间跳跃。每位访客的实验保存在自己的浏览器中，可通过 JSON 导入导出分享。

素材来源及许可见应用设置中的资料来源。音乐署名另见 assets/audio/credits.txt。

已知限制：强引力场景可能触发计算保护；不同设备的图形性能不同；一次孤立的三维启动失败尚未查明，不承诺全平台兼容。微信访问限制需要通过微信提供的正式申诉入口处理。

这个网址可以反复更新；本地编辑不会自动发布。发布内容标识见 release.json。
